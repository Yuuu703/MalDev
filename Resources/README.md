# Offline Lesson Library

A compact local reader containing both books and all 152 lessons: 94 in Malware Field Notes and 58 in MD-MZ Persistence Codex.

## Open it

Double-click `start-local.bat` or open `index.html` directly in your browser. Node.js, npm, and a background server are not needed.

The reader loads the small lesson catalog at startup and opens one lesson page at a time. Lesson images and video links load with that lesson; the 382 local illustrations are included in `assets_img/`.

The reading view keeps the lesson text, code examples, images, video embeds, and reference links. Outbound references and hosted videos still need their original servers. Two source image links contain malformed hostnames and remain unavailable.
