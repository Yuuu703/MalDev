Technical research note on Malware development trick. Run payload via EnumDesktopsA. covering source code implementations, evasion mechanics, and practical attack surface analysis.

Simple Nim example.

This post is just checking correctness of running payload via EnumDesktopsA in Nim programming language. EnumDesktopsA function passes the name of each desktop to a callback function defined by the application: BOOL EnumDesktopsA( HWINSTA hwinsta, DESKTOPENUMPROCA lpEnumFunc, LPARAM lParam );
