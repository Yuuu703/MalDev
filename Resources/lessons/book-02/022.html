API. Simple C example.

Like in the previous malware development trick example, this post is just for showing Proof of Concept. In the practice example with Telegram API, the attacker has one weak point: if the victim’s computer does not have a Telegram client or let’s say that messengers are generally prohibited in the victim’s organization, then you must agree that interaction with Telegram servers may raise suspicion (whether through a bot or not). Some time ago, I found a some interesting ideas of using VirusTotal API for stealing and C2-control logic. So, let’s implement it again by me. pracical example The main logic for stealing system information is the same as in the previous article. The only difference is using the VirusTotal API v3.
